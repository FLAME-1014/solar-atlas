参考 Solar System Atlas 的视觉和探索路径独立实现。功能复查与剩余精度差异见 [FUNCTION-AUDIT.md](./FUNCTION-AUDIT.md)；素材出处见 [ATTRIBUTION.md](./ATTRIBUTION.md)。

## 手机启动修复

启动不再依赖 import map；浏览器使用编译后的经典脚本包。基础场景先出现，贴图、星表、卫星与小行星资料随后按需加载。

WebGL 创建失败或图形上下文中断时自动进入 Canvas 2D 兼容视图，仍可搜索和阅读档案。程序加载失败时显示重试、兼容入口和独立文字资料版，避免停在没有提示的 0%。

移动版使用降采样贴图和较低像素比；自动档在低帧率时继续降低分辨率。GitHub 发布使用提交号更新脚本和样式的缓存版本。

## 本地启动

需要Node.js 20.10或以上。首次安装依赖，再启动：

```powershell
npm install
npm run dev
```

打开 http://127.0.0.1:4208/。也可双击 `启动图谱.cmd`。端口被占用时设置 `$env:SOLAR_PORT = '4210'`。

手机打开公网地址后，可使用浏览器“添加到主屏幕”安装。首次完成缓存后，即便暂时离线，也可打开文字资料页和已缓存的基础静态资源；天气、DSN和在线底图仍须联网。

`npm run build` 生成 `assets/app.bundle.js`、主屏图标和 `lite.html`。贴图与目录已保存在项目中，无需重新下载。`npm run assets:mobile` 生成移动贴图；`npm run weather` 获取新的全球天气采样快照，失败时保留已有资料。

## 数据精度

- 行星、小天体采用静态轨道根数和开普勒模型，不等于JPL高精度实时星历。卫星相位为近圆轨道示意。
- 图谱压缩尺寸与距离；飞行模式使用真实长度比例与简化牛顿引力。自动驾驶是导航辅助，不是燃料受限轨道规划。
- 任务状态与在轨目录带资料日期，不能把旧快照当作当前状态或卫星位置。
- 长期演化、磁层、宜居带、洋流与温盐曲线是明确标注的科普模型。
- 全球天气为带时间的经纬度采样插值，不是原站0.25°完整栅格；当前条件请用逐点气象。
- 地图提供在线影像/街道瓦片，但三维DEM地形与完整双语长文尚未达到原站同等范围。
- 兼容模式保留图谱与资料，不提供等同三维模拟的物理飞行控制。

## 验证

需要本机Chrome；Safari内核检查还需 `npx playwright install webkit`。

```powershell
npm run check
npm test
npm run test:mobile
npm run test:completion
```

- `check`：语法、目录唯一性、轨道边界、贴图、插画、恒星分块、小行星和天气文件。
- `test`：21项主要交互回归。
- `test:mobile`：Chrome、WebKit、无WebGL、贴图挂起、程序包失败。
- `test:completion`：新目录、地形、演化、DSN、波段、插画、物种与天气。

截图与JSON结果位于 `output/`，不进入Git。

## GitHub Pages

仓库根目录运行 `npm run build:site`，会先构建浏览器包，再生成到 `dist/`。Pages 工作流安装本项目依赖后执行同一命令并上传 `dist/`。

发布版直接查询支持跨域的公开服务，本地版使用 Node 代理。服务器、依赖和测试输出不上传网站。站点部署在仓库子路径 `/solar-atlas/`，资源均使用相对路径。
